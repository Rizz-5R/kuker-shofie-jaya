Frontend E-Commerce Mini Study Case

Project ini dibuat sebagai studi kasus pembelajaran frontend development menggunakan Vanilla JavaScript.

Tujuan utama project adalah memahami logic frontend secara bertahap dari sederhana hingga mendekati real-world mini ecommerce.


1. Product Data Management

Produk disimpan menggunakan JavaScript Object Array sebagai simulasi database sederhana.

Concept:
Source of Truth
Structured Data
Dynamic Rendering


2. Dynamic Product Rendering

Produk ditampilkan secara dinamis menggunakan DOM Manipulation.

Concept:
map()
innerHTML
createElement()
Dynamic UI Rendering


3. Direct Checkout System

Fitur "Pesan Sekarang" digunakan untuk checkout cepat 1 produk langsung ke WhatsApp.

Concept:
Event Listener
Dynamic Message
WhatsApp API


4. Shopping Cart System

User dapat menambahkan berbagai produk ke cart sebelum checkout.

Concept:
Array State
State Management Dasar
Render UI Realtime


5. Cart Merge Logic

Ketika user menambahkan produk yang sama berkali-kali, quantity akan bertambah tanpa membuat item baru.

Concept:
find()
Conditional Logic
Quantity Merging


6. Cart Persistence

Data cart disimpan menggunakan localStorage agar tidak hilang ketika halaman direfresh.

Concept:
localStorage
JSON.stringify()
JSON.parse()


7. WhatsApp Cart Checkout

Checkout cart mendukung:
Multi Product
Multi Variant
Dynamic Quantity
Dynamic Total Price


8. SEO Optimization

Website dioptimasi menggunakan:
Semantic HTML
Meta Tags
Open Graph
Sitemap
Robots.txt
